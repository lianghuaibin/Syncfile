# Syncfile — 局域网文件夹增量同步

通过局域网把手机上指定文件夹的全部内容（含子目录）上传到电脑/服务器的 Android App。

## 使用步骤

### 1. 电脑端启动接收服务器（零依赖，需要 Python 3）

```bash
python3 server.py
# 可选参数：
#   --port 9000            指定端口（默认 8000）
#   --root /path/to/dir    指定保存目录（默认 ./Syncfile）
#   --token my-secret      设置访问令牌（与 App 内填写一致）
```

启动后会打印本机局域网 IP，例如 `http://192.168.1.100:8000`。

> 首次运行如遇 macOS 弹窗，允许"接受传入网络连接"即可；
> 如连不上，检查电脑防火墙是否放行该端口。

### 2. 手机端安装并配置

1. 安装 `Syncfile-debug.apk`
2. 手机和电脑连到**同一个 Wi-Fi / 局域网**
3. 打开 App：
   - 「服务器上的目标文件夹」默认为**手机型号名**（如 `K70`），可直接修改；
     服务器上的完整路径为 `Syncfile/<目标目录>/<所选文件夹名>/内容相对路径`，
     例如选了 `DCIM` 文件夹 → `Syncfile/K70/DCIM/...`（所选文件夹名会一起上传；
     目标目录支持多级路径，用 `/` 分隔；留空则直接在 `Syncfile/<所选文件夹名>/` 下）
   - 点「选择要同步的文件夹」→ 系统文件夹选择器里选中目标文件夹
   - 填写服务器地址（电脑上打印的地址）和令牌（如有）
4. 点「开始同步」，通知栏和界面都会显示进度
5. **同步历史**：上传过的文件夹会记录在列表里（最近 5 个），
   下次打开 App 点一条记录即自动选中该文件夹并立即开始上传

### 3. 增量规则

上传前 App 会先询问服务器每个文件是否已存在（相对路径相同 + 大小相同 + 修改时间相同），
已存在则自动跳过。因此重复点击「开始同步」只会传输新增/有变化的文件。
文件修改时间会被还原到服务器上。

## 项目结构

```
app/src/main/java/com/syncfile/app/
  MainActivity.kt   界面：选文件夹、填地址、开始/停止、进度与日志
  UploadService.kt  前台服务：遍历文件夹、增量判断、重试、进度通知
  UploadClient.kt   HTTP 客户端：/check 与 /upload，流式上传（不占大内存）
  SyncState.kt      服务与界面之间的进度/日志共享状态
server.py           电脑端接收服务器（Python 标准库，单文件）
```

## 构建 APK

```bash
./gradlew assembleDebug     # 产物: app/build/outputs/apk/debug/app-debug.apk
```

（需 Android SDK；`local.properties` 中已指定本机 SDK 路径）

## 安全说明

- 协议为明文 HTTP，仅适合可信局域网；如需保护请设置 `--token`
- 服务器端对保存路径做了穿越校验，只能写入保存目录内

## 常见问题

- **同步中途失败/中断**：首次点同步时 App 会弹出「忽略电池优化」请求，请选择允许；
  息屏后系统（Doze）会掐断后台网络。
- **小米/华为/OV 等国产 ROM**：除电池优化外，还需在系统设置里给本 App 开启
  「后台运行/自启动」权限（各厂商路径不同：设置 → 应用管理 → Syncfile → 省电策略）。
